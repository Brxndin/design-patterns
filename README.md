# Design Patterns

Contém as atividades de Design Patterns para a cadeira de Padrões de Projeto de Software.

Por ser um repositório de atividades, não usei um padrão de pastas comum, então as pastas serão organizadas separando cada padrão de design e as dependências serão compartilhadas.

## Uso

Após baixar os arquivos ou clonar o repositório, entre na pasta e instale as dependências. Para isso, abra o terminal na pasta em que está o seu download (já extraído) e use os comandos abaixo:

```bash
cd design-patterns
npm i
```

Após isso, é possível rodar cada pattern separadamente. Abaixo seguem os comandos para cada um deles:

### Abstract Factory
```bash
npm run dev-abstract-factory
```

### Decorator
```bash
npm run dev-decorator
```

### Factory Method
```bash
npm run dev-factory-method
```

### Observer
```bash
npm run dev-observer
```

### Singleton
```bash
npm run dev-singleton
```

### State
```bash
npm run dev-state
```

### Strategy
```bash
npm run dev-strategy
```
